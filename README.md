# Sawstop-rail-drawer-3D-print
A drawer that fits inside the front rail of a Sawstop PCS for pencils, rules, etc.

Not my idea, but I made my own in OnShape CAD. I wanted to avoid having a slot
for the Sawstop rail bolt all the way to the front of the drawer, and I didn't see 
a need to do a multicolor front with a Sawstop logo on it, I wanted
to screw a wooden front on the drawer. And I wanted to learn a bit more
about OnShape.

Prints diagonally on the little bed of the Bambu A1 Mini. There should be an STL
and STEP files included.
